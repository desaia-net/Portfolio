# Anishi Desai — Personal Portfolio

React + TypeScript portfolio built with Vite.

## Run locally

Install Node.js (LTS), then from this folder run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Personalize before publishing

- Replace the LinkedIn, GitHub, and email placeholders in `src/App.tsx`.
- Add your résumé as `public/resume.pdf` (create `public/`) so the download buttons work.
- Replace project descriptions with details, screenshots, and links as you’re ready.
